# VfL Kirchheim Tournament Hub

Technisches Grundgerüst für die Verwaltung und Bewerbung von Jugendfußballturnieren.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint
- npm

## Starten

```bash
npm install
npm run dev
```

Die App ist anschließend unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Scripts

- `npm run dev` – Entwicklungsserver
- `npm run build` – Produktionsbuild
- `npm run start` – Produktionsmodus
- `npm run lint` – ESLint
